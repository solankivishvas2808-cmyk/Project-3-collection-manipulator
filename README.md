# 📖 Project Overview

Student Data Organizer is a menu-driven Python application developed to manage student records efficiently. The project demonstrates the practical implementation of Python's intermediate programming concepts including Lists, Tuples, Sets, Dictionaries, String Formatting, Type Casting, Mutability, Immutability, and the `del` keyword.

The application allows users to add, display, update, and delete student records while maintaining a unique collection of subjects. It provides a simple, organized, and user-friendly interface for managing student information.

---

- Develop a menu-driven Python application.

# 💡 Assumptions

- Every student has a unique Student ID.
- Student ID cannot be duplicated.
- Date of Birth follows the YYYY-MM-DD format.
- Subjects are entered as comma-separated values.
- Student ID and Date of Birth remain unchanged because they are stored in a Tuple.
- Mutable information such as Age, Grade, and Subjects can be updated.
