# 🎓 Student Data Organizer

## 👨‍💻 Author

**Vishvas Solanki**

**Course:** Bachelor of Commerce (B.Com)

## 📖 Project Overview

Student Data Organizer is a Python menu-driven application to manage
student records using List, Tuple, Set and Dictionary.

## ✨ Features

-   ➕ Add Student
-   📋 Display Students
-   ✏️ Update Student
-   ❌ Delete Student
-   📚 Display Subjects
-   🚪 Exit Program

## 🛠️ Technologies

-   Python 3
-   VS Code / Replit

## ▶️ How to Run

``` bash
python student_data_organizer.py
```
